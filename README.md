> A full-stack AI-powered interview platform that simulates real interviews using context-aware question generation and real-time audio communication.

| What | How |
|---|---|
| 🧠 **Intelligent Question Generation** | LangChain + Gemini generates questions dynamically from the user's resume, declared skills, and all prior answers in the session |
| 🎤 **Real-time Audio Interview** | WebRTC + Socket.io powers live audio streaming between the candidate and the AI interviewer |
| ⚡ **Low-latency Responses** | Redis caching reduced next-question API latency from **~8–10s → ~3–6s** |
| 🔊 **TTS Audio Output** | Streaming TTS integration reads AI-generated questions aloud in real time |
| 🔄 **Stateful Conversations** | MongoDB checkpointers maintain full session state across multi-turn dialogue |

### 🎬 AI Manim Video Generator
![Period](https://img.shields.io/badge/Jul_2025_–_Aug_2025-gray?style=flat-square)
![FastAPI](https://img.shields.io/badge/FastAPI-009688?style=flat-square&logo=fastapi&logoColor=white)

![Celery](https://img.shields.io/badge/Celery-37814A?style=flat-square&logo=celery&logoColor=white)
![Redis](https://img.shields.io/badge/Redis-DC382D?style=flat-square&logo=redis&logoColor=white)
![MongoDB](https://img.shields.io/badge/MongoDB-47A248?style=flat-square&logo=mongodb&logoColor=white)
![Docker](https://img.shields.io/badge/Docker-2496ED?style=flat-square&logo=docker&logoColor=white)
![GCP](https://img.shields.io/badge/GCP-4285F4?style=flat-square&logo=google-cloud&logoColor=white)
![Supabase](https://img.shields.io/badge/Supabase-3ECF8E?style=flat-square&logo=supabase&logoColor=white)

> An end-to-end AI pipeline that converts plain text prompts into fully rendered Manim animations using a self-healing multi-agent system.

| What | How |
|---|---|
| 🤖 **Multi-Agent Pipeline** | LangGraph workflow with specialized agents for code generation, validation, and error repair |
| 🔁 **Self-Healing Code Gen** | Validation + repair loops automatically detect and fix broken Manim code — boosted execution success from **~60% → 90%+** |
| ⚙️ **Concurrent Rendering** | Celery + Redis task queue handles multiple render jobs in parallel without blocking |
| 🎥 **Video Storage** | Rendered videos stored in **Supabase**, served back to the React frontend |
| ☁️ **Cloud Deployment** | Fully containerized with **Docker**, deployed on **Google Cloud Platform** |
